# 이세현 Product Manager 포트폴리오

제품의 범위를 정하고 티켓·명세·회의로 팀의 실행을 연결해 온 Product Manager 이세현의 웹 포트폴리오입니다.

## 소개

최종 PM 이력서를 바탕으로 CodeRun·MOG·HELIOS에서 맡았던 범위 결정, 비용 판단, 협업 구조와 검증 경험을 정리했습니다. 각 사례는 문제·제약, 판단과 실행, 확인한 결과, 한계와 다음 검증 순서로 구성했습니다.

이력서는 `public/leeseh-pm-resume.pdf`에서 제공합니다.

## 주요 프로젝트

- **CodeRun** — 한 달의 기간 안에서 핵심 학습 흐름을 정하고, 명세·MSW·티켓으로 FE와 BE의 실행을 연결
- **MOG** — 영수증 인식 비용의 손익분기점을 계산하고, API 명세와 성능 검증으로 제품 의사결정 지원
- **HELIOS** — 지도 탐색 성능과 AI 탐지 품질을 측정하고, 2인 팀의 일정·문서·역할 운영

## 주요 역량

- Product Management: 요구사항 정의, 범위 조정, 우선순위 결정
- Team Operations: 회의 운영, 일정 관리, 티켓 분해 및 의존관계 관리
- Metrics & Validation: 비용 비교, 성능 측정, 모델 결과 검수
- Collaboration: Linear, Notion, Swagger, Figma, MSW
- Technical Background: Spring Boot, React, Docker, AI/ML

## 실행

```bash
npm install
npm run dev
```
